# Redash 利用実績CSV

ChatGPTデスクトップのWorkで、ユーザーが開いたローカル作業フォルダを使う。作業フォルダを起点に `.env` と `csv/` を扱う。スキルに同梱された [export_usage.py](scripts/export_usage.py) をローカルのPythonで実行する。スキルの配置先と作業フォルダが異なる場合も、`--workspace` にはユーザーが開いたローカルフォルダを指定する。

## 初回セットアップ

利用者からセットアップガイドのURLを指定された場合は、そのガイドに従って専用のローカル作業フォルダを用意し、必要なファイルとチームの共通設定を配置する。アクセス許可など利用者の操作が必要な場合は、対象のパスと必要な操作を案内する。

1. ローカルのPython 3を確認する。macOSは `python3 --version`、Windowsは `py -3 --version` を使い、利用できなければ `python --version` で確認する。Python 3.9以上が見つからなければ、[Python公式ダウンロード](https://www.python.org/downloads/) の現在サポートされるPython 3を使い、許可された範囲でインストールを進める。利用者の操作が必要な場合は案内し、完了後に再確認する。追加ライブラリのインストールは不要。
2. `python3 "<スクリプトへのパス>" --workspace "<作業フォルダ>" init` を実行する。Windowsでは確認できたPythonコマンドを使う。テンプレートから `.env` を新規作成する処理なので、そのまま再実行しても既存ファイルは保持される。
3. 作業フォルダに `redash-team.env.example` があれば、`init` はそこから共通のURLとクエリIDを取り込む。`.env` の場所と、本人が入力する欄をコマンドの案内に沿って伝える。キーの値をチャットに求めたり、`.env` の内容を表示したりしない。以後の実行では設定を再利用する。

## 利用実績を取得する

1. 組織IDと取得期間を依頼文から取得する。組織IDがなければ確認する。期間の指定がなければ現行と同じ直近90日を使う。
2. 同梱スクリプトを次の形式で実行する。明示の日付範囲には `--start YYYY-MM-DD --end YYYY-MM-DD` を使う。

   ```text
   python3 "<スクリプトへのパス>" --workspace "<作業フォルダ>" export --org-id 12345 --days 30
   ```

3. 出力されたピボットCSVのパスを伝える。列は日付、行は組織・スペース名・ユーザー名、値は利用時間（分）で、行と列に合計を含む。エラーの場合は内容と再開に必要な操作を伝える。Pythonをローカルで起動できない実行環境では、ローカルで開いたWorkでの利用を案内する。
